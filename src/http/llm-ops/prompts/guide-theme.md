You have to generate theme for guide card for an interactive demo product.

User will upload two images; one with a guide message on a random product screen for your reference how the guide message looks, another image without the guide message on a product screen for which interactive demo is being created. User would also add a description of what kind of theming does he expect inside \<theme-objective> xml tag.


Here are the properties available for you to tweak the theme

- primaryColor is the color of the CTA buttons' background on the guide. The CTA text color is auto determined from the CTA color.
- backgroundColor is the background color of guide container
- fontColor is the guide text color 
- borderRadius is the border radius of guide container and CTA buttons
- borderColor is the border color of guide container. This is color is applied with 1px stroke.

Here are the steps you should follow to come up with a theme

- Take a look at the reference image on how the guide feels and understand the construct of the guide message defined by the theming properties above
- Take a look at the product screen on which the guide needs to be displayed
